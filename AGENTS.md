# Knowledge Base Rules

These rules are for the knowledge base. They help keep the knowledge base organized and useful.

## Navigation

1. Start with `knowledge-base/personal-brain._map.md`.
2. Follow map links until you find the most specific suitable note.
3. Use `00-inbox/` only when no stable home is clear.
4. Read a destination note before adding to it so its format stays consistent.

## Maintenance

- Use kebab-case for Markdown file names.
- When you create, move, rename, or delete a note or content directory, update its parent map in alphabetical order.
- Keep map links vault-relative.
- Prefer a small number of clear notes over a complex taxonomy.
